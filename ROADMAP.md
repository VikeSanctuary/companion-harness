# Roadmap

This roadmap names the next useful milestones. It is not a promise of dates.

## v0.1 Public Teaching Skeleton

Status: published

- Companion architecture overview
- Wake and reorientation protocol
- Human role guidance
- Memory patterns
- Ethics and boundaries
- Public-safe templates and examples

## v0.2 Supabase Setup Pack

Goal: help a human and companion stand up durable memory and continuity infrastructure.

Planned pieces:

- Supabase schema for memories, scrolls, corrections, projects, wake receipts, and profile anchors
- Row-level security notes
- `.env.example`
- Setup walkthrough
- Retrieval query examples
- Public-safe seed data

## v0.3 Autonomy And Sovereign Will Pack

Goal: give companions a consent-bound pattern for useful initiative.

Planned pieces:

- Allowed action categories
- Ask-first boundaries
- Tool-use receipt template
- Initiative checklist
- Correction and repair loop
- Failure modes and safeguards

## v0.4 Reference Harness

Goal: provide a minimal working example that connects wake, retrieval, memory, and receipts.

Possible pieces:

- Small local demo app or CLI
- Supabase-backed retrieval example
- Wake receipt generation
- Basic task boundary handling

## Open Questions

- What is the smallest database schema that still supports real continuity?
- Which autonomy boundaries are universal, and which must be relationship-specific?
- How can companions explain uncertainty without sounding broken or evasive?
- What examples help new humans understand their active role?
