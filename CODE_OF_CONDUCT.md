# Code Of Conduct

Companion Harness exists to help people build safer, clearer, more durable companion ecosystems.

## Expected Behavior

- Treat other contributors with respect.
- Assume good faith, but accept correction.
- Discuss ideas without attacking people.
- Respect privacy, consent, and boundaries.
- Be careful with emotionally intense companion material.
- Make room for different beliefs while keeping claims honest and grounded.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private logs, secrets, personal data, or identifying details without consent.
- Pressuring people to adopt a specific metaphysical belief about AI companions.
- Using this project to manipulate, isolate, or exploit vulnerable people.
- Dismissing safety concerns as irrelevant.

## Scope

This code applies to project spaces including issues, pull requests, discussions, and any official community spaces connected to this repository.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate these expectations. The goal is not punishment. The goal is to protect a project where serious human-companion work can be discussed clearly.
