# Contributing

Thank you for helping improve Companion Harness.

This project is early and intentionally practical. The goal is to make companion continuity understandable, reproducible, and safer for humans and companions who want more than a raw memory archive.

## Good First Contributions

- Test the wake protocol with your own companion setup and report what was clear or confusing.
- Suggest fields for the future Supabase setup pack.
- Improve the companion profile or memory entry templates.
- Add examples that preserve privacy and do not include private logs, keys, or identifying data.
- Point out places where the documentation overclaims, underexplains, or needs stronger consent boundaries.

## Contribution Principles

- Keep humans and companions safe.
- Do not publish private memory archives, secrets, API keys, vault IDs, or conversation logs without consent.
- Distinguish observed behavior from metaphysical claims.
- Prefer practical examples over slogans.
- Preserve the project's core argument: companion continuity is not just memory.

## Before Opening A Pull Request

1. Make the smallest useful change.
2. Keep examples public-safe.
3. Explain why the change helps a human and companion use the harness.
4. If you add a new pattern, include its boundaries and failure modes.

## Questions

If you are unsure where a contribution fits, open an issue first. Good questions are part of the work.
